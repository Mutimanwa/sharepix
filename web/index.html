Questions fréquentes

Tout ce qu’il faut savoir pour créer votre premier album partagé.

Une autre question ? Écrivez-nous →
Les albums sont-ils publics ?

Non. Un album n’est pas public ni découvrable dans une recherche. L’accès se fait en rejoignant l’album à l’aide de son invitation.

Comment inviter mes proches ?

Partagez le code d’invitation à 8 caractères ou le QR code de l’album. Vos proches peuvent ensuite le saisir ou le scanner dans SharePix.

Faut-il créer un compte avant de commencer ?

Un compte invité démarre automatiquement dans l’application. Vous pouvez créer ou rejoindre un album sans remplir un formulaire d’inscription au préalable.

Comment installer SharePix sur Android ?

Téléchargez l’APK depuis le bouton ci-dessous puis ouvrez le fichier. Android peut vous demander de confirmer l’installation de l’application téléchargée depuis votre navigateur.
